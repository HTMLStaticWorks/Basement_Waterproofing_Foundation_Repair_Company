FoundationGuard Documentation

Welcome to the FoundationGuard HTML5 & Bootstrap 5 contractor website documentation. This template is designed for basement waterproofing, structural foundation repair, and home service lead generation.

1. Getting Started

The template relies on standard modern web standards: HTML5, Bootstrap 5, CSS3 Custom Properties, and Vanilla JavaScript with optional GSAP scroll trigger animation support.

include CDN dependencies:
• Bootstrap 5.3.3 CSS & JS Bundle
• Bootstrap Icons 1.11.3
• GSAP 3.12.5 (ScrollTrigger)
• Google Fonts Archivo & Inter

3. Design System & CSS Tokens

Customize primary palette, safety orange accent, and dark mode tokens in assets/css/style.css:

:root {
  --fg-primary: #0F2C59;    /* Deep Navy */
  --fg-accent: #EA580C;     /* Safety Orange */
  --fg-secondary: #0284C7;  /* Hydraulic Blue */
  --fg-font-heading: 'Archivo', sans-serif;
  --fg-font-body: 'Inter', sans-serif;
}

4. Interactive Before/After Sliders

Before & After sliders use clean touch and drag events. Simply enclose elements in a .fg-ba-container wrapper:

<div class="fg-ba-container">
  <span class="fg-ba-tag fg-ba-tag-before">BEFORE</span>
  <span class="fg-ba-tag fg-ba-tag-after">AFTER</span>
  <!-- Before Image Visual -->
  <div class="fg-ba-after">
    <!-- After Image Visual -->
  </div>
  <div class="fg-ba-slider"><div class="fg-ba-handle"></div></div>
</div>
