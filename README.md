# FoundationGuard — Basement Waterproofing & Foundation Repair Website

FoundationGuard is a premium, high-converting HTML5 website template tailored for structural protection contractors specializing in basement waterproofing, foundation crack repair, sump pump installations, vapor barrier sealing, and exterior drainage.

## Key Features

- **11 Complete HTML Pages**:
  - `index.html`: Main Conversion-Focused Home Page
  - `home-2.html`: Genuinely Different Technical Contractor Layout with Interactive Self-Assessment Tool
  - `services.html`: Full Services Catalog with Interactive Category Filter
  - `service-details.html`: Detailed Service Page Template for Crack Repair
  - `before-after.html`: Dedicated Transformation Gallery with Interactive Image Comparison Sliders
  - `pricing.html`: Transparent Pricing Education Guide
  - `about.html`: Company Profile, Mission, Team, and Core Values
  - `reviews.html`: Homeowner Ratings & Testimonials
  - `contact.html`: Conversion-Focused Contact Page & Required Free Inspection Form
  - `404.html`: Contractor-Themed Error Page
  - `coming-soon.html`: Launch Countdown Page with Subscription Form

- **Design System & Aesthetics**:
  - Deep Navy, Charcoal, Concrete Grey, and Safety Orange construction visual language
  - Typography: Google Fonts Archivo & Inter
  - Light/Dark mode switcher with `localStorage` persistence and automatic system preference matching
  - Interactive Before & After comparison drag/touch sliders
  - GSAP scroll animations & Bootstrap 5 icons
  - Accessible mobile offcanvas navigation drawer with ESC key support and nested submenus
  - Form validation with toast notifications for Free Inspection requests
